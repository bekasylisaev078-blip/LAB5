# Lab 5 — Event Registration (Java console application)

Console application for managing event registrations. Data is kept in memory
(an `ArrayList`) and is lost when the program exits.

## Requirements
- JDK 17 or later
- Gradle (the Gradle wrapper is generated by the IDE / `gradle wrapper`)

## How to run
- In the IDE: open the project as a Gradle project and run `registration.Main.main()`.
- From the terminal: `./gradlew run --console=plain` (Windows: `gradlew.bat run --console=plain`).

## Classes (package `registration`)
- **Registration** — one registration: private fields (`id`, `fullName`, `email`,
  `studentGroup`, `eventTitle`), constructor, getters, `toString()`.
- **RegistrationManager** — owns the `ArrayList<Registration>`; validation rules,
  add (automatic unique IDs), show all, find by ID, delete by ID, filter by event.
- **Main** — console menu with `Scanner`; reads input, handles errors
  (`NumberFormatException`) and calls the manager.
